# BVideoconverter Free Trial

Free Trial version of BVideoconverter for Linux Mint/Ubuntu.

## Installation

1. Download the .deb file from Releases.
2. Run the installer: chmod +x bvideoconverter_install.sh
./bvideoconverter_install.sh

3. Launch: Search "BVideoconverter" in menu.
