## Installation (Linux Mint / APT-based systems)

Two installer script names are provided for compatibility and convenience:

- `bvideoconverter_install.sh` (legacy / compatibility name)
- `bvcinst.sh` (short name)

Both scripts contain the same functionality.

### 1. Download the installer

Download **one** of the following files from this repository:

- `bvcinst.sh` (recommended)
- or `bvideoconverter_install.sh`

### 2. Make the script executable

GitHub browser downloads do **not** preserve executable permissions, so this step is required:

```bash
chmod +x bvcinst.sh
```

### 3. Mint File browser
or the Linux Mint GUI style, just browse to the saved file with Mint´s file browser and click the file active and right click it and
from the file properties open Rights, Execute:, and check the box: Allow file to execute as a program. 

### 4. Run the installer script

Then to install from the script run in terminal:

```bash
sudo ./bvcinst.sh
```
### or if you downloaded the bvideoconverter_install.sh (make sure it´s this new version)
```bash
sudo ./bvideoconverter_install.sh

```

### 5. Run the program from OS´s Menu

Launch: Search "BVideoconverter" in menu.
or BVideomuunnin in Finnish
